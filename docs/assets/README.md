# Documentation assets

This directory contains the two original/balanced/strong comparisons displayed
near the top of the main README.

## Files and reproducibility

The fabric files are 1200 x 900 pixels. The raven-feather files are 1200 x 800
pixels. The original images were encoded as progressive JPEG, quality 94, with
4:4:4 chroma. The processed images were produced by Nevermoire 0.1.0 using the
exact commands in the main README.

All six public files are metadata-free: they contain no EXIF, XMP, IPTC, GPS,
comments, orientation tags, ICC profile, or device metadata.
