## Files and reproducibility

`unsplash-feathers-original.jpg` is a metadata-free 1200 x 900 crop from an
auto-oriented 1600 x 2253 derivative of the 3545 x 4991 official download.
The intermediate derivative was resized with Lanczos3; the public crop was
encoded as progressive JPEG, quality 94, 4:4:4 chroma.

`unsplash-feathers-balanced.jpg` and `unsplash-feathers-strong.jpg` were
generated from that derivative by Nevermoire 0.1.0 using the exact commands in
the main README. All three public files contain no EXIF, XMP, IPTC, GPS,
comments, orientation tags, ICC profile, or device metadata.
